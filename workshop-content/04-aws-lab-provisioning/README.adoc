= Module 4 lab assets — Delivering with AI

Timed team challenge (groups of four, one hour). Learner steps live in `documentation/modules/ROOT/pages/04-aws-lab-provisioning.adoc`.

Teams start from a *blank slate*—create your Ansible project under this directory on your `group_<team_number>` branch. No starter playbooks are provided.

Work on branch `group_<team_number>` (example: `group_1`).

Never commit AWS access keys, secret keys, or `credentials.yml`.
