== Category notes

* *Creativity* — interesting design, demo, or failure story; not flash for its own sake
* *Met requirements* — fault tolerant; Ansible for app *and* AWS; code on `group_<n>` when time was called
* *Time to create* — working demo inside the hour; unfinished work scores lower
* *Ansible best practices* — idempotent playbooks, variables (not hardcoded secrets), clear roles/playbooks, no one-off click-ops
* *Cost* — how the team planned to manage AI usage costs while creating and deploying the application (models, prompt strategy, spend awareness)

Winning team: *100 Reward Zone points*, split among the four members.
