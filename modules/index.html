Accelerating Ansible Delivery with AI

Welcome to the Accelerating Ansible Delivery with AI!

Overview

Accelerating Ansible Delivery with AI provides a hands-on learning experience focused on applying AI-assisted development workflows to Ansible automation. Participants build a Cursor workspace, migrate legacy shell scripts to Ansible, analyze the cost factors of AI code assistance, and compete in a timed team challenge to deploy a fault-tolerant web application on AWS.

Practical Exercises

Through a series of progressive labs, you’ll gain practical experience with:

  • Cursor Workspace Setup: Build and configure an AI-assisted development workspace using Cursor

  • Shell-to-Ansible Migration: Refactor legacy shell scripts into an Ansible project using multiple AI models to compare their performance and output

  • Managing AI Costs: Analyze and manage the cost factors associated with AI code assistance

  • Delivering with AI: In randomly assigned groups of four, design, develop, and deploy a fault-tolerant web application on AWS using Cursor AI and Ansible

Prerequisites

Before starting this workshop, ensure you have:

  • Basic understanding of Linux command line operations

  • Familiarity with YAML syntax and shell scripting

  • Podman installed and configured on your local machine (required for Lab 1 Dev Containers and for previewing this documentation locally)

  • A Cursor account (setup covered in Lab 1)

This workshop does not require pre-provisioned OpenShift, AAP, Showroom, or other platform services. Lab exercises run in your local Cursor workspace via Podman. Preview and refresh this documentation with the Antora viewer container — see the Appendix.

Lab Structure

The workshop is organized into four sequential modules:

  1. Cursor Workspace Setup: Build and configure an AI-assisted development workspace using Cursor

  2. Shell-to-Ansible Migration: Refactor legacy shell scripts into Ansible using multiple AI models

  3. Managing AI Costs: Analyze and manage cost factors associated with AI code assistance

  4. Delivering with AI: Team challenge — deliver a fault-tolerant web application on AWS with Cursor AI and Ansible

Learning Outcomes

By the end of this workshop, you will be able to:

  • Configure Cursor as an AI-assisted development environment for Ansible work

  • Compare AI model outputs when refactoring legacy shell scripts into Ansible

  • Identify and manage cost factors related to AI code assistance

  • Design and present a fault-tolerant AWS web application that is deployed and updated with Ansible

Getting Started

To view these labs in a browser, launch the Antora viewer with Podman as described in View Workshop Documentation Locally.

Begin with Module 1: Cursor Workspace Setup. Each module includes detailed instructions, exercises, and verification steps.

For questions or issues, refer to the Appendix or contact your instructor.
