= {lab_name}

Use Codex or Cursor with Ansible to migrate a Python NetBox installer, compare AI model usage, and complete a team deployment challenge on AWS.

== Prerequisites

* Basic Linux command-line skills and familiarity with YAML and scripting.
* A RHEL or macOS workstation with a working Ansible installation.
* Permission to install your chosen AI tool and access to enterprise Codex or an approved Cursor account.
* Optional Podman access to preview the documentation locally.

Lab 2's generation and review steps run on your workstation.
Optional deployment checks need a disposable CentOS Stream 10 VM.
Lab 4 uses an AWS sandbox.
The workshop does not require OpenShift, AAP, or Showroom services.

== Labs

. xref:01-cursor-workspace.adoc[Workspace setup]. Configure Codex or Cursor with your local Ansible tools, using the CLI or desktop interface.
. xref:02-shell-to-ansible.adoc[Python-to-Ansible NetBox migration]. Write your own prompt, experiment with the tools, and review attempts to migrate the legacy installer.
. xref:03-managing-ai-costs.adoc[Managing AI costs]. Repeat the migration with different models and record usage, time, and corrections.
. xref:04-aws-lab-provisioning.adoc[Delivering with AI]. Work in randomly assigned groups of four to design and deploy a fault-tolerant web application on AWS with Cursor and Ansible.
