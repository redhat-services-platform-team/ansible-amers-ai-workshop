Welcome to the {lab_name}!

== Overview

{lab_name} provides a hands-on learning experience focused on applying AI-assisted development workflows to Ansible automation. Participants build a Cursor workspace, migrate legacy shell scripts to Ansible, analyze the cost factors of AI code assistance, and provision AWS lab infrastructure.

== Practical Exercises

Through a series of progressive labs, you'll gain practical experience with:

* **Cursor Workspace Setup**: Build and configure an AI-assisted development workspace using Cursor
* **Shell-to-Ansible Migration**: Refactor legacy shell scripts into an Ansible project using multiple AI models to compare their performance and output
* **Managing AI Costs**: Analyze and manage the cost factors associated with AI code assistance
* **AWS Lab Provisioning**: Provision lab infrastructure in an AWS demo environment utilizing an AI code-assist setup

== Prerequisites

Before starting this workshop, ensure you have:

* Basic understanding of Linux command line operations
* Familiarity with YAML syntax and shell scripting
* *Podman* installed and configured on your local machine (required for Lab 1 Dev Containers and for previewing this documentation locally)
* A Cursor account (setup covered in Lab 1)

NOTE: This workshop does not require pre-provisioned OpenShift, AAP, Showroom, or other platform services. Lab exercises run in your local Cursor workspace via Podman. Preview and refresh this documentation with the Antora viewer container — see the xref:appendix.adoc[Appendix].

== Lab Structure

The workshop is organized into four sequential modules:

. **xref:01-cursor-workspace.adoc[Cursor Workspace Setup]**: Build and configure an AI-assisted development workspace using Cursor
. **xref:02-shell-to-ansible.adoc[Shell-to-Ansible Migration]**: Refactor legacy shell scripts into Ansible using multiple AI models
. **xref:03-managing-ai-costs.adoc[Managing AI Costs]**: Analyze and manage cost factors associated with AI code assistance
. **xref:04-aws-lab-provisioning.adoc[AWS Lab Provisioning]**: Provision lab infrastructure in an AWS demo environment with AI code-assist

== Learning Outcomes

By the end of this workshop, you will be able to:

* Configure Cursor as an AI-assisted development environment for Ansible work
* Compare AI model outputs when refactoring legacy shell scripts into Ansible
* Identify and manage cost factors related to AI code assistance
* Provision AWS lab infrastructure using AI-assisted development workflows
