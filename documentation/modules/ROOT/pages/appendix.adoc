[#view-workshop-docs-locally]
== View Workshop Documentation Locally

Workshop documentation is built with Antora and previewed locally with Podman.
You do not need OpenShift or a Showroom deployment to read or refresh the lab content.

=== Prerequisites

* *Podman* installed and working on your workstation (only needed for this optional documentation preview)
* A local clone of this workshop repository

=== Launch the Antora viewer

. Clone this repository (if you have not already) and change into the repository root.
. Commit your content to git before previewing — Antora only indexes committed files when using the local content source (`url: .` in `default-site.yml`).
. Start the Antora viewer container:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

On SELinux-enabled systems (for example Fedora or RHEL), append `:z` to the volume mount:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora:z -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

. Open a browser to link:http://localhost:8080[http://localhost:8080,window=_blank].

Live-reload is not supported. When you change documentation, stop the container and start it again so Antora rebuilds the site.

[#refresh-local-docs]
== Refresh Local Documentation

As the workshop progresses, documentation may be updated in the repository.
To pick up those changes in your local Antora preview:

. Stop the running Antora container (for example press `Ctrl+C` in the terminal where it is running, or run `podman stop antora`).
. Pull the latest changes from the repository if updates were published remotely (`git pull`).
. Ensure any local documentation edits you want to preview are committed.
. Start the Antora viewer again with the same `podman run` command from the previous section.

Once the container is running, the updated content is available at link:http://localhost:8080[http://localhost:8080,window=_blank].
