[abstract]

== Learning Objectives

After completing this module, you will be able to:

* Install and configure Cursor for Ansible development
* Set up project workspace conventions for the workshop
* Use Cursor AI features relevant to automation development

== 1: Cursor Overview

Cursor is an AI-powered code editor built on VS Code. It provides integrated AI assistance for writing, reviewing, and refactoring code — including Ansible playbooks, roles, and collections.
